# المسبحة الصوتية — خطوات تحويلها إلى تطبيق أندرويد

محتويات المجلد:
- index.html: التطبيق نفسه
- manifest.json: بيانات التطبيق (الاسم، الأيقونة، الألوان)
- sw.js: يجعل التطبيق يفتح بدون إنترنت
- icons/: أيقونات التطبيق

## الخطوة 1: رفع الملفات على الإنترنت (مجانًا)
أسهل طريقة هي Netlify Drop:
1. فك ضغط الملف على الكمبيوتر.
2. افتح https://app.netlify.com/drop
3. اسحب مجلد tasbih كاملًا إلى الصفحة.
4. ستحصل على رابط مثل https://xxxx.netlify.app

(بديل: GitHub Pages)

## الخطوة 2 (الأسهل): تثبيته مباشرة من المتصفح
افتح الرابط في Chrome على الجوال ← القائمة ⋮ ← "تثبيت التطبيق" أو "إضافة إلى الشاشة الرئيسية".
سيظهر كتطبيق مستقل بأيقونته.

## الخطوة 2 (للحصول على ملف APK أو النشر على Google Play)
1. افتح https://www.pwabuilder.com
2. الصق رابط موقعك واضغط Start.
3. اختر Package for stores ← Android ← Generate.
4. نزّل الملف المضغوط؛ ستجد بداخله:
   - ملف .apk للتثبيت مباشرة على الجوال
   - ملف .aab للرفع على Google Play
   - ملف signing.keystore وبيانات التوقيع: احتفظ بها جيدًا، فهي مطلوبة لأي تحديث لاحق.
5. لإزالة شريط العنوان داخل التطبيق: ارفع ملف assetlinks.json (الموجود في الحزمة) إلى المسار
   /.well-known/assetlinks.json على موقعك.

## ملاحظات
- التطبيق الناتج يعمل عبر Chrome، ولذلك يعمل فيه التعرف على الصوت.
- التعرف على الصوت يحتاج إنترنت؛ العد اليدوي يعمل بدونه.
- عند أول استخدام للميكروفون سيطلب التطبيق الإذن؛ اختر "السماح".
- لتحديث التطبيق: عدّل الملفات وأعد رفعها، وغيّر tasbih-v1 إلى tasbih-v2 في sw.js.
